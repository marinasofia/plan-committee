# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be welcoming and respectful, assume good intent, give feedback on the work and not the person, and no harassment of any kind.

To report a problem, use **Report a vulnerability** in the Security tab (it is private) or contact the maintainer through their GitHub profile. Reports are kept confidential.
